## Tecnologias do portfólio

Construído com **Angular 20**, **TypeScript**, **HTML** e **CSS**, com **RxJS** e integração de contato via **EmailJS**.

A estrutura utiliza componentes reutilizáveis, dados separados da apresentação, carregamento de páginas sob demanda e fontes locais. As animações são feitas com CSS e Intersection Observer.
