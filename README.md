# HEITOR.DEV — Portfólio

Portfólio pessoal construído com **Angular + React + TypeScript**, com foco em landing pages, projetos Full Stack e apresentação profissional.

## Stack

- Angular 20
- React 19
- TypeScript
- Framer Motion
- Lucide React
- HTML / CSS

## Por que Angular + React?

O Angular funciona como a aplicação principal e organiza a estrutura, navegação, estado do formulário e filtros. O React é integrado em um widget isolado para demonstrar componentes interativos e animações com Framer Motion.

Isso mantém cada tecnologia com uma responsabilidade clara, em vez de misturar os frameworks indiscriminadamente.

## Como executar

```bash
npm install
npm start
```

Depois acesse `http://localhost:4200`.

## Build

```bash
npm run build
```

## Organização

- `src/app/app.component.*` — estrutura principal do portfólio.
- `src/app/react-widgets/` — integração React + Framer Motion.
- `src/styles.css` — estilos globais.
- `src/assets/` — imagens, ícones e outros assets.
